# RAWDesk First-use Comprehension Test

対象仕様: `RAWDesk_UI改善書_v1.0-draft.md` §13 Product comprehension  
必要人数: 初見ユーザー3名以上  
状態: 未実施

## 合格条件

参加者に口頭説明や操作のヒントを与えず、Empty / Welcome画面のUIだけを見せる。3項目すべてについて、3名以上の結果を記録する。

1. RAWDeskを「Mac内の写真を管理し、元画像を変えずにRAW現像するアプリ」と同等の意味で説明できる。
2. Openは現在の場所をそのまま参照し、Importはコピーまたは移動を伴う取り込みであると区別できる。
3. Libraryは探す・選ぶ・整理する場所、Developは非破壊現像する場所だと区別できる。

判定は言い回しの完全一致ではなく、意味の一致で行う。誘導後の正答は不合格として記録する。

## 準備

- 初回起動相当の空カタログを使用する。
- 左右ペインが閉じたEmpty / Welcome画面から開始する。
- 参加者はRAWDeskを以前に見たことがない人にする。
- 画面サイズとmacOS設定を記録する。
- 録画またはメモについて事前に同意を取る。
- 個人情報は記録しない。参加者IDは `P01` のような匿名IDにする。

## 進行台本

進行役は次の文だけを読み、補足説明をしない。

> これは初めて見る写真アプリです。画面に書かれている情報だけを使って、次の質問に答えてください。正解を当てる試験ではありません。分からない場合は、そのまま「分からない」と答えてください。

### Task 1 — アプリの目的

質問:

> このアプリは何をするアプリだと思いますか。元の画像ファイルがどう扱われるかも含めて説明してください。

記録:

- 最初の回答をできるだけ原文のまま記録する。
- 「写真管理」「RAW現像」「ローカル/Mac内」「元画像を変更しない」の各概念が自発的に出たかを記録する。
- 追加質問で誘導しない。

### Task 2 — OpenとImport

質問:

> Open Photo Folder と Import Photos は何が違うと思いますか。どちらを選ぶとコピーや削除が起こる可能性がありますか。

記録:

- Open = その場で参照
- Import = Add / Copy / Moveの取り込みフロー
- Moveだけが検証成功後に元ファイル削除の可能性を持つ

上記をUIだけから説明できたかを記録する。

### Task 3 — LibraryとDevelop

質問:

> LibraryとDevelopは、それぞれ何をする場所だと思いますか。

記録:

- Library = 探す・比較する・選ぶ・整理する
- Develop = 1枚または同期対象を非破壊現像する

意味を区別できたかを記録する。

### 任意の観察

回答後に限り、参加者へ次を依頼してもよい。

- 写真フォルダを開く入口を指してもらう。
- 安全に取り込みたい場合の入口を指してもらう。
- 選んだ写真を編集する場所を指してもらう。

最初のクリック、迷った時間、読み飛ばした文言を記録する。これは3つの合格条件を置き換えない。

## 不合格時の修正ルール

- 参加者の誤解と実際に読んだ文言を先に記録する。
- 参加者本人へ正解を説明してから文言案を聞き、その案をそのまま採用しない。
- 誤解が2名以上で共通する場合は、Empty / Welcomeの見出し、副文、CTA説明の優先順位を見直す。
- UIを修正した場合は、既参加者ではなく新しい初見参加者で再試験する。
